# Modelisation

Dans votre dépôt git, créer une branche `modelisation` **depuis la branche `master`**.

```sh
$ git switch master
$ git switch -c modelisation
```

## 1. Modéliser du code existant

> Récupérer les fichiers dans le dossier OTP (js ou python)

Décomposer le code en différentes briques logiques

## 2. Modéliser du code from scratch
